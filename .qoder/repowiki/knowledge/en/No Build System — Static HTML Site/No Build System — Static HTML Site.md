This repository is a plain static multi-page website (HTML, CSS, JavaScript) for an electrical appliance repair shop. There are no build scripts, dependency manifests, container definitions, CI pipelines, or packaging tooling present in the codebase. The site is served as-is without compilation, bundling, minification, or deployment automation.
