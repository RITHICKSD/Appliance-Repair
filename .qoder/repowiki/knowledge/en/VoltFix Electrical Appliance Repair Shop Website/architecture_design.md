Flat static-site layout — no build toolchain or server runtime. Each HTML file (index.html, home2.html, about.html, services.html, pricing.html, guides.html, contact.html, guide-details.html, service-details.html) is an independent page that loads the same shared assets: Tailwind CSS via CDN with a custom `tailwind.config` extending slate/indigo color tokens and Inter/Outfit fonts; FontAwesome 6 icons; `css/style.css` for page-specific overrides; and two client-side scripts loaded at the bottom of `<body>` — `js/data.js` (pure mock data exports: `servicesData`, `articlesData`, `coverageZipCodes`, `faqsData`) consumed by content pages, and `js/app.js` (global UI manager bootstrapped on `DOMContentLoaded` that wires theme toggle, LTR/RTL direction switch, dropdowns, and the mobile drawer). Pages are linked to each other via relative hrefs; there is no templating engine, so header/footer markup is duplicated across files rather than shared through a server-side include.
